## 3. 接口测试用例

### 3.1 用户注册接口

**接口**: `POST /api/auth/register`

#### TC-API-REG-001: 正常注册

**请求**:
```json
{
  "email": "test@example.com",
  "password": "password123",
  "username": "testuser",
  "verifyCode": "123456"
}
```

**响应**:
```json
{
  "success": true,
  "data": {
    "user": {
      "id": "uuid",
      "email": "test@example.com",
      "username": "testuser"
    },
    "token": "jwt-token"
  },
  "message": "注册成功"
}
```

**断言**:
- ✓ HTTP状态码: 200
- ✓ success字段为true
- ✓ 返回用户ID和Token
- ✓ 不返回密码字段

---

#### TC-API-REG-002: 参数缺失

**请求**:
```json
{
  "email": "test@example.com"
  // 缺少password和username
}
```

**响应**:
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "参数验证失败",
    "details": [
      {
        "field": "password",
        "message": "密码不能为空"
      }
    ]
  }
}
```

**断言**:
- ✓ HTTP状态码: 400
- ✓ success字段为false
- ✓ 返回详细错误信息

---
